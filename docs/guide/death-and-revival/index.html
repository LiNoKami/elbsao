Before a fight

  • Check the current rules for the server and mode you are playing.
  • Confirm whether party members can use Revive Crystals and how they are obtained.
  • Agree on a retreat route and when to disengage.

Revive Crystal

The client describes a 30-second use window, a 12-block range and revival at 25% HP in hardcore worlds. The current server rules and crystal availability still need confirmation.
